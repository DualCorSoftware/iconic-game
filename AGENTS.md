# Iconic Game - Agent Guidelines & Rules

## Core Rules

### Punctuation & Formatting
- **No Em Dashes**: Absolutely NEVER use em dashes (Unicode U+2014) in any files, SVG metadata, documentation, commit messages, or responses. Always use standard ASCII hyphens/dashes (`-` or `--`).

### Asset Standards
- All SVG icons must be valid XML with `fill="currentColor"`.
- SVGs must reside in `icons/svg/`.
